# MedVault — Clinical Notes

Prototipo de gestor local de notas, desarrollado con HTML, CSS y JavaScript puro.

## Archivos
- `index.html`: estructura de tres paneles.
- `styles.css`: tema oscuro responsivo con acentos teal.
- `app.js`: estado `notas`, búsqueda, filtros, edición y guardado local.
- `medvault-logo.png`: logotipo.

Mantén todos los archivos en la misma carpeta. Para evitar limitaciones del almacenamiento al abrir un archivo local, ejecútalo desde un servidor estático o publícalo como sitio estático.

**Privacidad:** `localStorage` no cifra los datos y no sincroniza entre dispositivos. Las notas iniciales son ficticias. No introduzcas datos identificables de pacientes en este prototipo.
